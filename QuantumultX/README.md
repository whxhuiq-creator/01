# Quantumult X 策略组图标

五个图标统一为 144×144、8-bit RGBA、非动画 PNG，与本仓库现有 QX 图标规格一致；保持原图比例。

| 图标 | 原始素材 |
| --- | --- |
| Crunchyroll.png | 本仓库 Crunchyroll.png |
| Pixiv.png | 本仓库 Pixiv.png |
| BOOKWALKER-JP.png | 本仓库 BOOKWALKERJP-Official.png |
| BOOKWALKER-TW.png | 本仓库 BOOKWALKERTW-Official.png |
| Amazon.png | [Hawaiine/Oasisic-Icons](https://github.com/Hawaiine/Oasisic-Icons/blob/main/icons/Shopping/Amazon.png) |

在 QX 配置的 `img-url` 中使用 `raw.githubusercontent.com` 图片直链。例如：

```text
https://raw.githubusercontent.com/keixhuiq/Icon-Library/main/QuantumultX/Amazon.png
```
