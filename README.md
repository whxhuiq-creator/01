# 图标库

补充一些不常见的 Quantumult X 策略组图标。

仓库中的策略组图标统一为 Quantumult X 支持的 108×108 PNG。

## Quantumult X 使用说明

Quantumult X 需要使用 `raw.githubusercontent.com` 图片直链，不能使用 GitHub 的 `blob` 页面链接。

例如，U-NEXT 的可用链接是：

```text
https://raw.githubusercontent.com/Keixhuiq/Icon-Library/main/U-NEXT.png
```
